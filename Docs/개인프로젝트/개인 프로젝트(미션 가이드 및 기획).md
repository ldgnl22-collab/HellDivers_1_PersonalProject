## 개인 프로젝트

### 만들 것 (미션 가이드)
> 주제
- HellDivers 1편 모작 - 탑뷰 시점 액션 슈터 (PC, 싱글 플레이)

> 장르 특성
- 위에서 비스듬히 내려다보는 카메라로 캐릭터를 조작하며 몰려오는 적을 처치하고, 방향키 코드를 입력해 궤도 지원(스트라타잼)을 호출하며 임무를 완수하고 탈출하는 게임

> 핵심 조작 재미
- 전투 중 코드를 입력하는 긴장감, 상황에 맞는 무기 교체, 지원을 언제 어디에 떨어뜨릴지 고르는 판단

> 개발 규모
- 1인 개인 프로젝트 / Unity (3D)

> 진행 기간
- 2026.11.06 ~ 2026.11.24

### 목표 (모작 범위)
- 시스템 구조 (시점, 무기교체, 스트라타잼 호출, 임무와 탈출) 구현

### 필수 유저 체험 및 기획 요소
- 사방에서 몰려오는 적 사이에서 버텨야 하는 **생존 압박**

- 전투 도중 코드를 입력해야 해서 생기는 **조작 긴장감** (입력하는 동안 사격할 수 없다)

- 탄약, 지원 횟수, 쿨타임이 제한되어 **언제 쓸지 고민하는 자원 전략**

- 지원이 하늘에서 떨어져 적을 쓸어버릴 때의 **한 방 쾌감**

- 목표를 완수하고 탈출 지점에서 버티다 빠져나올 때의 **클리어 성취감**

### 필요 기능
> 메인 화면 / 출격 준비
- 게임 타이틀, 게임 시작, 옵션, 종료 버튼
- 출격 전 **로드아웃 화면** : 주무기 1종, 스트라타잼 4종 선택 출격

> 입력 시스템 (필)
- Input System으로 입력을 구성
- 이동 : WASD 
/ 조준 : 마우스 커서 위치 
/ 사격 : 마우스 왼쪽 
/ 재장전 : R 
/ 무기 교체 : 1, 2 키 또는 휠
- 스트라타잼 메뉴 : 좌측 Ctrl을 누르고 있는 동안 메뉴가 열리고, 방향키로 코드를 입력
- 메뉴가 열린 동안에는 같은 방향키가 이동이 아니라 코드 입력으로 해석되어야 한다

> 구상할 알고리즘
> - 같은 키가 상황에 따라 다른 의미를 갖는다. 입력을 "지금 어떤 모드인가"에 따라 나누는 구조를 어떻게 만들 것인가?
> - 메뉴를 닫는 순간 입력 중이던 코드는 어떻게 처리할 것인가?
>> 나의 구상안
>> - 나누는 구조 : Ctrl키 입력 여부
>> - 코드 처리 : 초기화

### 활용해야 할 기술
- Input System : Action Map을 나눠 스트라타잼 메뉴가 열렸을 때 방향키 해석을 바꾼다.

- 오브젝트 풀 : 탄환, 적, 이펙트처럼 반복 생성되는 오브젝트에 적용한다.
