## 발표 준비

1. 발표 조건
- 목적 : 프로젝트에서 핵심 기능을 구현한 방법 소개
- 청중 : 같이 공부하는 학생들
- 시간 : 5분

2. 프로젝트 발표

- 만든 것 : 스트라타잼의 방향키 비교 기능(간단 게임소개 및 기능소개)

- 실제 동작 : 

- 구현한 방법 : 
- 1. 구조 : 입력한 것의 정보와 몇번째 입력인지 확인하여 스트라타잼 데이터의 앞자리 정보와 비교하고 참 거짓으로 분류
- 2. 핵심 코드 : 체크할 스트라타잼 데이터의 정보를 담은 리스트에 참 값만 넣은 리스트를 복사하여 반복 비교(복사 전 클리어)

- 이 방법을 고른 이유 : 
- 1. 다른 방법과의 비교 : 처음에 시도한 방법은 입력 값 정보가 일치하지 않으면 리스트에서 제외를 반복
- 2. 판단 근거 : 제외 시키는 것 만으로는 반복되는 구조에서 앞의 입력에 대한 비교결과를 알지 못하면 현재 입력 인덱스와 값만 비교하기 때문에 정확한 비교가 되지 않는다.

- 어떤 문제가 있었고 어떻게 풀었는가 : 
- 1. 문제 : 리스트 하나에서 입력 값과 맞지 않으면 제외하는 방법에서는 첫번째 값에서 걸러도 두번째 값에서 걸러지지 않을 수 있다.
- 2. 접근 : 입력 값과 같은 정보를 가진 데이터만 모아서 저장하고 다음 비교에서는 그 데이터들만 비교하면 될 것이라고 생각했다.
- 3. 결과 : 의도한 대로 동작하였다

목차는 게임소개와 핵심기능소개, 구현 방법 회고로 준비하였습니다.
게임은 헬 다이버즈1 을 레퍼런스로 미션가이드를 받아 만들었습니다
이 게임의 핵심기능은 스트라타잼으로 방향키를 알맞은 순서로 입력하면 전투에서 지원을 받을 수 있습니다.
먼저 기능구상 인데요 사용자가 입력한 인덱스와 키정보를 스트라타잼 데이터의 정보와 비교하여 같으면 리스트에 유지하는 방식으로 구상했습니다.
루프를 돌며 후보를 좁혀나가는 형태입니다 값이 같으면 리스트에 저장하고 다음 루프 시 그 리스트를 검사합니다.
처음 구상한 아이디어 리스트에서 일치하지 않으면 제외한다.
사용자가 입력한 인덱스의 데이터를 각 스트라타잼 리스트의 인덱스와 비교하여 같으면 저장합니다
